# Календарь релизов

Общий календарь продуктов и релизов на 2026–2036 годы. Самостоятельная регистрация отключена. Все вошедшие пользователи видят общие данные.

## Запуск для разработки

Требуется Node.js 22 или новее.

Создайте файл `.env` по образцу `.env.example` и задайте собственные `ADMIN_LOGIN` и `ADMIN_PASSWORD`. Логин не зависит от регистра, пароль зависит. Файл `.env` содержит секреты и не должен попадать в Git. Администратор создаёт пользователей с ролями РП и DevOps через кнопку «Пользователи» и может изменить их роль или пароль, а также удалить пользователя. При смене роли, пароля или удалении активные сессии пользователя завершаются. Пароли пользователей хранятся в базе в виде хешей.

РП создаёт и изменяет продукты и создаёт релизы; DevOps видит календарь и карточки, но не создаёт продукты и релизы. Новый релиз получает статус «Запланирован». РП может отклонить запланированный релиз; DevOps может взять его в работу и затем отметить выполненным. Администратор может выполнить любой из этих переходов.

```sh
npm ci
npm run dev
```

Для Docker после заполнения `.env` выполните `docker compose up --build -d`. При изменении `.env` пересоздайте контейнер той же командой. Сессии действуют 12 часов и сбрасываются при перезапуске сервера. Для доступа по сети настройте HTTPS в Caddy.

Vite выводит адрес интерфейса в консоль и перенаправляет запросы `/api` на сервер. Данные хранятся в SQLite-файле `data/vacations.db`; путь можно изменить через `DB_PATH`, порт API — через `PORT`.

Для сборки и запуска готового приложения:

```sh
npm run build
NODE_ENV=production npm start
```

`npm test` запускает тесты, `npm run typecheck` проверяет типы. При первом запуске миграция удаляет пользователей и отпускные дни старого шаблона. Сохраните резервную копию существующей базы перед обновлением, если эти данные нужны.

Создайте продукт в панели справа, затем создайте релиз кнопкой вверху или через выбранный день. Цветной индикатор управляет видимостью отметок продукта только в текущем окне браузера. Список обновляется при возвращении фокуса на страницу.
